## What are the Withering Realms minimum system requirements?

The official Steam listing requires a 64-bit processor and operating system. Its current minimum specification is designed for Windows 10, DirectX 11, and 14 GB of available storage.

| Component | Minimum requirement |
| --- | --- |
| Operating system | Windows 10, 64-bit |
| Processor | Intel Core i5-2500K or AMD Ryzen 5 1400 |
| Memory | 8 GB RAM |
| Graphics | NVIDIA GeForce GTX 970 or AMD Radeon RX 570 |
| DirectX | Version 11 |
| Storage | 14 GB available space |

## What are the recommended PC specs?

Steam's recommended specification keeps the same Windows 10 and 14 GB storage requirements but raises the CPU, memory, graphics, and DirectX targets.

| Component | Recommended requirement |
| --- | --- |
| Operating system | Windows 10, 64-bit |
| Processor | Intel Core i7-8700K or AMD Ryzen 5 3600X |
| Memory | 12 GB RAM |
| Graphics | NVIDIA GeForce GTX 1070 or AMD Radeon RX Vega 56 |
| DirectX | Version 12 |
| Storage | 14 GB available space |

## Can a PC below the minimum run the game?

The developer does not publish performance targets, resolution, frame rate, or settings for either tier. A lower-spec computer may launch the game, but there is no official basis for promising acceptable performance. Treat the minimum table as the supported floor until benchmarks from the released Early Access build are available.

## Does Withering Realms support macOS or Linux?

No macOS or Linux version is currently listed on Steam. The confirmed Early Access platform is Windows PC. The [platform and console guide](/guides/platforms-console-release) tracks those announcements separately.

## Could these requirements change during Early Access?

Yes. Moonless Formless says systems and balance may change during Early Access, and PC requirements can also be revised before or after launch. This page will follow the official Steam listing rather than unofficial hardware estimates.
