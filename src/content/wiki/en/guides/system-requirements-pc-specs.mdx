The official **Withering Realms system requirements** tell you which PC components Steam currently lists, but they do not say what frame rate, resolution, or graphics preset each tier targets. The minimum specification calls for 64-bit Windows 10, 8 GB of RAM, 14 GB of storage, and either a GeForce GTX 970 or Radeon RX 570. The recommended tier raises the processor, memory, graphics card, and DirectX version while keeping the same operating-system and storage entries. Use these tables as a compatibility checklist, not a performance guarantee. Requirements may still change before or during Early Access, so compare them with your actual hardware and recheck the Steam listing near launch.

## What are the Withering Realms minimum system requirements?

Steam currently lists the following minimum PC specification:

| Component | Minimum requirement |
| --- | --- |
| Operating system | Windows 10, 64-bit |
| Processor | Intel Core i5-2500K or AMD Ryzen 5 1400 |
| Memory | 8 GB RAM |
| Graphics | NVIDIA GeForce GTX 970 or AMD Radeon RX 570 |
| DirectX | Version 11 |
| Storage | 14 GB available space |

The listing also requires a 64-bit processor and operating system. It does not provide minimum performance targets, so the table should not be translated into a guaranteed resolution or frame rate.

## What are the recommended Withering Realms PC specs?

The recommended tier keeps Windows 10 and 14 GB of storage, then raises CPU, RAM, GPU, and DirectX requirements:

| Component | Recommended requirement |
| --- | --- |
| Operating system | Windows 10, 64-bit |
| Processor | Intel Core i7-8700K or AMD Ryzen 5 3600X |
| Memory | 12 GB RAM |
| Graphics | NVIDIA GeForce GTX 1070 or AMD Radeon RX Vega 56 |
| DirectX | Version 12 |
| Storage | 14 GB available space |

## What changes between minimum and recommended?

| Area | Difference |
| --- | --- |
| CPU | i5-2500K / Ryzen 5 1400 to i7-8700K / Ryzen 5 3600X |
| Memory | 8 GB to 12 GB RAM |
| GPU | GTX 970 / RX 570 to GTX 1070 / RX Vega 56 |
| DirectX | Version 11 to Version 12 |
| Windows and storage | No listed change |

This comparison shows component tiers only. Steam does not attach presets, resolution, frame rate, ray tracing, upscaling, or SSD requirements to either tier.

## Can a PC below the minimum run Withering Realms?

It might launch, but there is no official basis for promising stable or acceptable performance. Treat the minimum table as the listed floor. Reliable below-minimum advice requires testing the released build on named hardware rather than extrapolating from trailers or another game.

## Withering Realms system requirements FAQ

### How much RAM does Withering Realms need?

Steam lists 8 GB RAM minimum and 12 GB RAM recommended.

### How much storage space is required?

Both tiers list 14 GB of available storage. Steam does not currently specify an SSD.

### What graphics card is required?

The minimum is a GTX 970 or RX 570. Steam recommends a GTX 1070 or RX Vega 56.

### Does Withering Realms support Windows 11?

Steam lists Windows 10, 64-bit. It does not separately document Windows 11 compatibility, so this page does not promise it before testing or an official update.

### Does Withering Realms support macOS or Linux?

No macOS or Linux version is currently listed. The confirmed Early Access platform is Windows PC; the [Withering Realms platform guide](/guides/platforms-console-release) tracks future platform announcements.

## How should you prepare your PC?

Compare your CPU, GPU, and installed RAM with the official tiers, keep at least 14 GB free, and recheck Steam before launch in case the listing changes. Then review the [Withering Realms gameplay overview](/guides/gameplay-overview) and [Early Access release details](/guides/release-date-early-access) for what the launch build is expected to include.
