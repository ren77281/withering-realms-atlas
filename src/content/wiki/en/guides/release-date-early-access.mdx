## When will the full version launch?

Steam currently expects the game to leave Early Access in **May 2027**, which is a Q2 2027 target rather than a guaranteed date. A console release is planned around the full release, but no named console versions have been announced. The [Withering Realms console and platform guide](/guides/platforms-console-release) tracks those announcements without treating an unconfirmed PS5, Xbox, or Nintendo version as fact.

## What may change during Early Access?

The developer's current plans include more language support, end-game features and modes, fixes, balance updates, and system improvements. Exact weapon values, item effects, enemy tuning, progression routes, and performance advice should therefore be treated as version-sensitive while the Early Access build changes. ## Withering Realms release date FAQ

### Did Withering Realms release on September 4, 2026?

Yes. The current Steam listing and official launch announcement show September 4, 2026. The official website still shows September 2, so check both sources when quoting the date.

### Is the September launch the full release?

No. It is the Windows PC Early Access launch. A separate full-release date has not been announced.

### Can you play the full story in Early Access?

The launch announcement says the current English build is playable from start to finish. More languages, end-game features and modes, fixes, and balance or system changes are still planned.

### What is planned after the Early Access launch?

The developer plans additional language support, end-game features and modes, and continued fixes, balance updates, and system improvements before the full release.

### Is Withering Realms coming to consoles at Early Access launch?

No console launch is announced for Early Access. Steam lists a console release around the planned full release, but the platforms have not been named.
