The **Withering Realms release date** can be confusing because Early Access and the eventual full release are separate milestones. The developer's official website lists **September 2, 2026**, for the Windows PC Early Access launch. It also says the initial build will be playable from start to finish, rather than offering only part of the main story. However, additional side quests, end-game modes, balance work, and system changes are still planned. Steam currently targets a 2027 exit from Early Access alongside a console release, but no exact full-release date or named console version has been announced. This guide separates those confirmed details from expectations that the developer has not promised.

## What is the Withering Realms release date?

The developer lists **September 2, 2026**, as the Steam Early Access date. This first launch is for Windows PC, not the final multi-platform release.

## What will Withering Realms Early Access include?

Moonless Formless says the Early Access build will be **playable from start to finish**. That is a statement about the main playable arc, not a claim that every optional activity or balance value will already be final.

The developer currently plans three types of post-launch work before full release:

- Additional side quests.
- Additional end-game modes.
- Changes to game systems and balance based on player feedback.

## When will the full version launch?

Steam's current Early Access statement says the game is planned to leave Early Access in **2027**, alongside a console release. No day or month is announced, and plans can change during development. The official website says console versions are planned after Early Access concludes but does not identify the consoles. The [Withering Realms console and platform guide](/guides/platforms-console-release) tracks those announcements without treating an unconfirmed PS5, Xbox, or Nintendo version as fact.

## What may change during Early Access?

The developer explicitly names **game systems** and **balance** as areas that may change. Exact weapon values, item effects, enemy tuning, progression routes, and performance advice should therefore be treated as version-sensitive once players can test the game. Pre-release trailer footage is not a substitute for hands-on verification.

## Withering Realms release date FAQ

### Is Withering Realms releasing on September 2, 2026?

The official website says Steam Early Access begins September 2, 2026. Steam may show September 3 in some regions, so verify the local store date near launch.

### Is the September launch the full release?

No. It is the Windows PC Early Access launch. A separate full-release date has not been announced.

### Will the Early Access build contain the full story?

The developer says it will be playable from start to finish. More side quests, end-game modes, and system or balance changes are still planned.

### Is Withering Realms coming to consoles at Early Access launch?

No console launch is announced for Early Access. The developer plans console versions for the full release after Early Access ends.

## What should you expect at launch?

Expect a start-to-finish Early Access build on Windows PC, not a content-complete final version.
