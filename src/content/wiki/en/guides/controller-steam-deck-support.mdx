## Does Withering Realms have full controller support?

Yes. Steam currently labels Withering Realms with **Full controller support** and separately lists DualShock and DualSense controller support. This is the strongest official confirmation available before the Early Access release.

| Controller question | Current official answer |

| Full controller support | Listed on Steam |
| DualShock support | Listed on Steam |
| DualSense support | Listed on Steam |
| Exact button prompts | Not published |
| Full input remapping | Not published |

## Is Withering Realms Steam Deck Verified?

No Steam Deck compatibility rating is currently shown in the official store data. That means the game should not yet be described as Verified, Playable, or Unsupported. A Windows release and controller support are useful signals, but neither proves Deck compatibility or performance.

## Will Xbox controllers work?

Steam's general Full controller support label suggests the game is intended to be playable with a controller, but the current feature list explicitly names only DualShock and DualSense families. Official sources do not yet document Xbox button prompts, controller models, or input-remapping options, so those details remain open.

## What should Steam Deck players check at launch?

After Early Access begins, check the Steam Deck compatibility badge first. If no rating appears, the practical questions are whether the game launches through Proton, displays readable text, provides correct controller prompts, and maintains stable performance. This page will not substitute community guesses for an official rating.
