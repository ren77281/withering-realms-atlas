The **Withering Realms Institute puzzle** uses book-word pairs, according to Steam players. This explanation assumes you already have the clue and books. We have not tested it in-game. The diagrams are editorial illustrations, not gameplay screenshots.

## How do you read the Institute book-word code?

Read the first number as the book number and the second as the word number. For example, `1-6` means book 1, word 6.

![Book-word pair: select book 1, then word 6](/images/articles/institute-pair.svg)

## In which order should you read the pairs?

Work left to right, keeping each pair together. The sequence below is an invented teaching example, not a game password.

![Illustrative sequence: book 1 word 5, book 2 word 3, book 1 word 4](/images/articles/institute-order.svg)

## Can you copy another player's code?

Use your own clue. Comment 17 reports a different sequence that worked with the same method. This does not establish when codes are generated or whether re-entry changes them.

![Two different illustrative clues decoded with the same method](/images/articles/institute-own-clue.svg)

## Quick questions

### Should I rearrange the books?

The reported method selects a book, then a word; it does not rearrange books.

### Where are the missing books?

Pickup locations remain unverified here.

### Does this cover the bathroom or clock?

No. Those puzzles need separate evidence.
